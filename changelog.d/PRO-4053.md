- Upgrading from 2.8.x: the upgrade guide and the user guide now cover a store that copied 2.8.x into `app/code/Smaily/SmailyForMagento` instead of installing it with composer. Delete that folder first, then install version 3 with composer or from the release ZIP; the 2.8.x settings carry over as on a composer store. Installed beside the old copy, version 3 left the 2.8.x module enabled.
