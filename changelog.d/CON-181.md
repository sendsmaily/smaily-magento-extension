- A store-created visitor token (`vs_…`, which a separate storefront or a customization may set; the extension creates none) now reaches Campaign Intelligence only when the shopper has given marketing consent, as in the WooCommerce plugin: with a guest order, with a login, with browse events and when a guest's storefront recommendations are fetched. The extension counts consent when Magento's **Cookie Restriction Mode** is on and the shopper has accepted the cookie notice on that website; without it, the order, the login and the events go without that token. Browse events now carry the visitor token from the shopper's cookie only, and a token named in a browse event that the storefront posts is ignored, so a separate storefront no longer sends it. Visitor tokens from Smaily email links (`vt_…`) work as before.
