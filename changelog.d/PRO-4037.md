- The contacts import card no longer offers an import that cannot send yet, and says why one sent nothing. On a website whose Contacts settings are not saved yet (**Settings > Contacts**, or the initial setup's Contacts step), **Start import** stays disabled and the card says "Contacts start syncing to Smaily once the Contacts settings are saved, so an import would send nothing yet. Save them to import." Before, it was offered and ended with only "Done, 0 of 0 synced." An import that sent nothing from a website because its contact sync was off now adds "Contact sync was off for <website>, so nothing was sent from there. Turn it on and save the Contacts settings, then press Run again." `bin/magento smaily:backfill:start contacts` says so for each such website too.
