- When a Campaign Intelligence history import stops before it is complete — you cancel the **Orders** import, or the **Catalog** or **Customers** import before the **Orders** import has begun, or the **Orders** import stops before an error or stays **Stalled** — the extension tells Campaign Intelligence once that it stopped and why, so Campaign Intelligence no longer waits for the rest. **Run again** on the **Orders** card starts a new history import.
