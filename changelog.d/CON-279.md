- A store with more than one website can be set up as **Separate stores**: the initial setup first asks **How are your websites run?**, and with **Separate stores** each website gets its own Smaily account, Contacts settings, automations and transactional-email account, set up and shown on its own with a website selector at the top of the initial setup and **Settings**. **One store in several versions** works as before. **Change** under **Your websites** switches later: to separate stores, each website keeps its current settings as its own; back to one store, the settings of the website you are looking at become the settings for all websites. A store whose websites have different Smaily logins and none for all websites (carried over from 2.8.x or set up on an earlier release candidate) is read as separate stores, and each website keeps sending with the workflows it used before, now saved as its own. Campaign Intelligence stays one connection for all websites in this release.
