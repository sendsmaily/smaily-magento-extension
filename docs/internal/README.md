# Maintainers' working papers

The documents in this folder are working papers of the extension's
maintainers. They are not merchant documentation: they record plans, checks
and reviews while the work is in progress, and they can be out of date. For
how to install, set up and use Smaily Connect, read the
[User Guide](https://smaily.com/connect-magento/), [Installing](../INSTALLING.md) and
[Upgrading](../UPGRADING.md).

| Document | What it is |
|---|---|
| [BACKLOG.md](BACKLOG.md) | Known deferred work |
| [PILOT_CHECKLIST.md](PILOT_CHECKLIST.md) | The checklist for a pilot store install |
| [RFC_MULTI_WEBSITE.md](RFC_MULTI_WEBSITE.md) | The design of multi-website support |
| [ADMIN_UI_TARGET_SPEC.md](ADMIN_UI_TARGET_SPEC.md) | The target specification of the admin pages |
| [audits/](audits/) | Dated audits and reviews; each one describes the code as it was on its date |

A finished document is deleted, not kept here; git history keeps its text.
