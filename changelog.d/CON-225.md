- `bin/magento smaily:gdpr export` now lists the discount codes the extension made for the shopper — each code, when it was made, its last valid day and whether it was used — and `bin/magento smaily:gdpr erase` deletes the ones never used and prints a line for them, **Discount codes**. A used code stays, because its order still names it, and codes you generated yourself in Magento are never changed. A code is found while the email it went out in is still in the Log.
