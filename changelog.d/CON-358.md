- A product description built with Page Builder, or holding a widget or an image inserted from the media gallery, now reaches the RSS product feed, Campaign Intelligence and the products in abandoned-cart emails as its text only: the description's style rules and its `{{widget …}}` and `{{media url=…}}` codes no longer show as text, paragraphs no longer run together, and HTML from a Page Builder **HTML Code** element no longer shows as code. Products already sent to Campaign Intelligence get the clean description only through a catalog import: press **Run again** on the **Catalog** card under **Settings > Intelligence**.
