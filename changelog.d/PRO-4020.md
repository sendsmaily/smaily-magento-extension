- Hyvä stores install the Hyvä compatibility module (`smaily/module-connect-hyva`) with one composer command that installs Smaily Connect too — until 3.0.0 is released, with the release candidate's exact version for both packages; from 3.0.0 on, `composer require smaily/module-connect-hyva` — or from the release's second ZIP, `smaily-connect-magento2-hyva.zip`, extracted into `app/code/Hyva/SmailyConnect`. Copying the module from a clone of the source repository is no longer needed; the user guide's Hyvä section has the steps.
