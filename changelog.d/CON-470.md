- A store with several websites run as one store on one Smaily account now shares its Smaily account, Contacts settings and automations across all its websites: **Settings** shows them once, for all websites, with no website selector, and a save there applies to every website. A store set up on 3.0.0-rc1 to rc12 whose settings sit on one website only gets them on every website with this upgrade, so the other websites' newsletter signups reach Smaily and start the welcome email from now on; to send the signups made there before, press **Run again** on the **Initial contact import** card under **Settings > Contacts**. A signup on a website that still has no Smaily connection shows in the **Log** as **Skipped**, and the **Dashboard** names such websites, and says so when your websites use different Smaily accounts.
