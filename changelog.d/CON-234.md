- When a Smaily account is connected, the extension sends Smaily an installation report when you save the settings, once a day, and when you remove a connection or remove the module, authenticated with the connected Smaily account's API credentials, which Smaily only checks and never stores: the store addresses, the Magento, PHP and extension versions, the connected Smaily accounts, the switched-on features, whether each connection works (error codes only) and the time of the last successful sync — never customer, subscriber or order data. A report that fails never affects the store and shows no notice. See [What data goes where](https://smaily.com/connect-magento/#pr-data).
