- The Log (**Last Error** and **Details**) and the extension's log file no longer keep the text of Smaily's, Campaign Intelligence's or the database's error messages, which can contain a customer's name or email address: an error now reads in the extension's own words with the HTTP status and the error code (for example "Smaily API returned code 203", or "price: rejected by engine" for a refused product field). Rows recorded before the update keep their text until the Log removes them after 30 days (sent) or 90 days (failed).
