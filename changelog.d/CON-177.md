- A link that carries a store-created visitor token (`smaily_vt=vs_…`) no longer sets the shopper's visitor-token cookie, in Magento's own storefront and on Hyvä, as in the WooCommerce plugin. Campaign Intelligence puts only its own `vt_` tokens in email links, so a `vs_` token in a link is one its sender chose; before, such a link could plant a token its sender knew, which Campaign Intelligence then tied to the shopper at their next guest order. Links from Smaily emails work as before, and a `vs_` token the shopper's browser already holds is still sent with the order.
